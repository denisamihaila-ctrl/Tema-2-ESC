# Tema-2-ESC
~Tema de casa 2 - Mihăilă Denisa-Maria - 3112b~

In tema aceasta voi crea o aplicație cu ajutorul HTML, CSS si JavaScript care genereaza random o fraza tehnica utilizând Techy API.

# API folosit
**Techy API**  
Endpoint: https://techy-api.vercel.app/api/json  

API-ul returnează un obiect JSON care conține un câmp numit `message`, 
iar aplicația afișează acest mesaj în interfața web.

## Tehnologii utilizate

- HTML – structurarea paginii
- CSS – stilizarea interfeței
- JavaScript – logica aplicației și integrarea API-ului
- Git & GitHub – managementul versiunilor

## Funcționalități

- Preluarea unei fraze tehnice random de la Techy API
- Afișarea dinamică a mesajului în pagină
- Afișarea metadatelor (lungime mesaj, număr de cuvinte, momentul încărcării)
- Buton pentru generarea unei noi fraze
- Tratarea erorilor și afișarea stării de încărcare

## Cum se folosește aplicația

1. Deschide fișierul `index.html` într-un browser.
2. La încărcarea paginii, este afișată automat o frază tehnică.
3. Apasă butonul **„Generează o nouă frază”** pentru a încărca un mesaj nou.
